# The House of Brews — Farewell

A single-page farewell site for The House of Brews in Jensen Beach, Florida.

Static HTML + CSS, with [jQuery](https://jquery.com) (loaded from the jQuery CDN) for the
fade-in and scroll-reveal animations. No build step required.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | Page markup |
| `styles.css` | Oak / amber / gold theme drawn from the hero image |
| `script.js` | jQuery animations |
| `images/hero.png` | Hero image |

## Running locally

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
```
